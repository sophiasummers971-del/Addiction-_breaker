# Getting started with Addiction Breaker

Addiction Breaker is a reflection and support web app. You can use its guest tools without signing in.

## 1. Open the app

Visit **https://addiction-breaker.pages.dev/**. Select a support journey or choose **General / not sure**, then continue as a guest. On a mobile screen, look for the bottom navigation and **More** menu.

## 2. Try one small step

- **Check-in:** record how today feels. Entries belong to the chosen journey, so you can keep different topics separate.
- **Pause:** try the ten-minute pause and write your next step.
- **Journal:** revisit or edit earlier notes and use search/date filters.
- **Plan:** write a personal plan at your own pace. The plan is shared across journeys.
- **Mirror:** if relevant, select a supported gambling-history export to examine descriptive patterns locally. A file is not a clinical assessment, and incomplete data cannot establish exact losses.

## 3. Choose how your notes are saved

**Nothing is automatically permanent in guest mode.** Guest journal entries start in page memory. If you refresh or close the page, unsaved notes can disappear. The **Remember my journal** option enables browser storage on that device; anyone with access to that browser profile may be able to see it. This storage and downloaded backups are **not encrypted**.

You can also use Google sign-in where configured. Signing in is not consent to upload guest notes. Cloud sync, and importing guest notes into an account, require separate choices. Synced data is not end-to-end encrypted. An online session check is required to reopen an account journal, so account access is not fully offline.

Find export/restore and device-erasure controls under **Support**; account controls are under **Account**. Erasing this device does not automatically remove cloud records.

## 4. Know what this tool cannot do

The app is not a medical service, a diagnosis, or emergency response. It does not monitor distress or automatically contact emergency services. The experimental gambling Hook Score is an unvalidated descriptive index, not a relapse forecast or severity score. Do not use the app to plan alcohol or drug withdrawal.

Use the **Support** area for links to relevant organisations. For urgent danger or a medical emergency, contact the appropriate emergency service.
