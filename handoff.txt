DELIVERED
A standalone Node web app with zero runtime dependencies. Start with npm start;
open http://127.0.0.1:3737 on the same computer. No account, database or AI key.

Today: validated daily check-ins, opt-in browser persistence and personal plan.
Pause: ten-minute timer with practical actions; resets on reload.
Journal: earlier exact-text Echoes, recent averages, edit/delete, export/restore.
Mirror: memory-only CSV/TSV/TXT/JSON upload processing; fictional demo; supported
counts and narrative, data-quality warnings, unknown results when money or
outcome coverage is missing, clear-analysis action.
Support: NHS/GamCare links including text routes, privacy and evidence notes.
Offline shell: service worker caches static assets only. Analysis needs server.

CORRECTNESS / SECURITY
Fixed startup's undeclared Express/Multer dependency by using Node HTTP.
Corrected loss streak and bet-to-bet acceleration calculations.
Historical RTP is no longer automatically treated as expected future RTP.
Removed claims of individual platform targeting from generated narratives.
Experimental Hook Score is subordinate to counts and explicitly unvalidated.
Echoes require explicit non-play, a note, and a strictly earlier date.
Uploads: 2 MiB, 20,000 rows, 100 users; missing, malformed and mixed-currency
values are handled explicitly. Static routes are allowlisted. Same-origin/host
checks, CSP and baseline security headers are applied. No raw HTML rendering
of personal/imported text. No application logging of uploaded content.
Damaged saved data and cross-tab changes pause writes to prevent overwrite.
Journal backups are versioned and validated before replacement.
